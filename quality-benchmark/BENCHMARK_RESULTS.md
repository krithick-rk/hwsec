## 1. Executive Summary

This report documents the baseline accuracy metrics for the **HWSEC Security Analysis Framework** evaluated against the verified installed benchmark datasets. Findings generated by HWSEC's detection adapters (Semgrep pattern SAST, Joern CPG dataflow engine, and CodeQL integration) were evaluated directly against the authoritative ground truth manifest (`manifests/ground_truth.json`).

> - **True Positives (TP)**: Ground truth vulnerabilities correctly identified and flagged by HWSEC.

> - **True Negatives (TN)**: Non-vulnerable test cases correctly recognized and ignored.
